# ElementSmith

An accessible, composable interface system and interactive component playground built with semantic HTML, modern CSS, and vanilla JavaScript. The project uses native Web Components rather than React or TypeScript.

The site includes a filterable component catalogue, live property controls, copy-ready generated markup, light and dark themes, and keyboard-complete modal, dropdown, tabs, and notification patterns.

## Local development

```bash
pnpm install
pnpm run dev
pnpm run build
```
