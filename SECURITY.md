# Security Policy

## Supported versions

ElementSmith is currently pre-1.0. Security fixes are applied to the latest revision on the `main` branch.

## Reporting a vulnerability

Do not disclose a suspected vulnerability through a public issue.

Use GitHub’s **Private vulnerability reporting** feature on the repository’s Security tab when it is available. Otherwise, contact the repository owner privately through the contact method listed on the [owner’s GitHub profile](https://github.com/ayosomo).

Include:

- the affected file, component or workflow;
- clear reproduction steps;
- the observed and expected behaviour;
- the likely impact;
- any suggested mitigation;
- whether the issue has been disclosed elsewhere.

You should receive an acknowledgement within seven days. Please allow time for investigation and a coordinated fix before public disclosure.

## Scope notes

Reports about dependency vulnerabilities, unsafe generated markup, cross-site scripting, exposed credentials or insecure deployment behaviour are in scope. General feature requests and accessibility bugs should use the normal issue templates.
